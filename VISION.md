# Crepe in Casa

## Dominio
https://crepeincasa.it

## Obiettivo

Costruire un portale italiano specializzato in:
- crepe nei muri;
- fessurazioni;
- cedimenti;
- problemi del terreno;
- fondazioni;
- consolidamento fondazioni;
- micropali;
- resine espandenti;
- sottofondazioni.

Il sito deve acquisire traffico organico da persone che osservano un problema nel proprio immobile e cercano informazioni.

Il sito non deve effettuare diagnosi strutturali online.

## Modello commerciale

Il sito:
1. informa;
2. aiuta l'utente a raccogliere dati utili;
3. permette di inviare una richiesta strutturata;
4. con consenso esplicito, può trasmettere la richiesta a professionisti o imprese partner compatibili con la zona.

Monetizzazione futura:
- vendita lead qualificata;
- abbonamento territoriale;
- accordo mensile/rank-and-rent;
- altra forma commerciale con partner.

## Posizionamento

Il brand deve essere:
- indipendente;
- serio;
- tecnico ma comprensibile;
- prudente;
- non allarmistico.

Il sito non deve sembrare:
- un'impresa di consolidamento mascherata;
- un sito clickbait;
- un servizio diagnostico;
- un sito AI;
- una macchina aggressiva per raccogliere lead.

## Principio di sicurezza

Non diagnosticare mai da:
- fotografie;
- descrizioni;
- questionari.

Non concludere online:
- che una crepa è strutturale;
- che un edificio è sicuro o insicuro;
- che esiste un cedimento;
- che serve sicuramente un consolidamento;
- quale tecnica è necessaria.

Usare formulazioni prudenti:
- può essere associato a;
- tra le possibili cause;
- può meritare una verifica;
- una valutazione sul posto è necessaria per stabilire la causa.

In situazioni potenzialmente urgenti, invitare l'utente a rivolgersi tempestivamente a un professionista qualificato o alle autorità competenti, senza sostituirsi a loro.

## Strategia SEO

Partire da cluster reali:

### Crepe
- crepe nei muri;
- crepe diagonali;
- crepe verticali;
- crepe orizzontali;
- crepe sopra porte e finestre;
- crepe muri esterni;
- crepe casa vecchia;
- crepe che aumentano.

### Cedimenti
- cedimento fondazioni;
- cedimento terreno;
- cedimento differenziale;
- pavimento che sprofonda;
- casa che cede.

### Soluzioni
- consolidamento fondazioni;
- micropali;
- resine espandenti;
- sottofondazioni.

### Costi
- costo consolidamento fondazioni;
- costo micropali;
- costo resine.

### Local
Solo dopo aver validato la struttura e, preferibilmente, sulla base dei dati Search Console.

## Lead

Il form deve raccogliere informazioni utili ma neutrali.

Non deve produrre una diagnosi.

Deve creare soltanto:
> Riepilogo delle osservazioni fornite dall'utente.

## Tecnologia

Preferenza:
- Astro;
- output statico;
- GitHub Pages;
- GitHub Actions;
- dominio custom crepeincasa.it;
- JavaScript minimo;
- contenuti separati dalla presentazione;
- backend separato per lead/upload;
- nessun secret nel repository.
