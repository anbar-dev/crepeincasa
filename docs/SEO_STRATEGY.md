# SEO Strategy — Crepe in Casa

## Obiettivo

Intercettare utenti italiani nelle varie fasi del problema:

1. osservazione della crepa;
2. ricerca delle possibili cause;
3. comprensione dei segnali da annotare;
4. valutazione delle possibili tecniche;
5. ricerca di costi;
6. richiesta di un professionista.

## Cluster 1 — Crepe

Query principali:
- crepe nei muri;
- crepe diagonali;
- crepe verticali;
- crepe orizzontali;
- crepe sopra porte;
- crepe sopra finestre;
- crepe muri esterni;
- crepe muri interni;
- crepe soffitto;
- crepe pavimento;
- crepe casa vecchia;
- crepe che aumentano.

Ogni pagina deve rispondere a un intento distinto.

## Cluster 2 — Cedimenti

- cedimento fondazioni;
- cedimento terreno;
- cedimento differenziale;
- casa che cede;
- pavimento che sprofonda.

## Cluster 3 — Soluzioni

- consolidamento fondazioni;
- micropali;
- resine espandenti;
- sottofondazioni.

Queste pagine devono spiegare le tecniche senza consigliare una soluzione specifica per un caso individuale.

## Cluster 4 — Costi

- costo consolidamento fondazioni;
- costo micropali;
- costo resine fondazioni;
- fattori che influenzano il prezzo.

Evitare prezzi locali inventati.

## Cluster 5 — Informazioni pratiche

- come monitorare una crepa;
- come misurare una crepa;
- quali foto preparare;
- quali informazioni dare a un tecnico;
- quando chiedere una verifica professionale.

## Local SEO

Possibili URL futuri:
- /consolidamento-fondazioni/como/
- /consolidamento-fondazioni/monza/
- /consolidamento-fondazioni/milano/
- /consolidamento-fondazioni/bologna/
- /consolidamento-fondazioni/ravenna/

Non generare automaticamente città.

Una pagina locale deve essere pubblicata solo se:
- esiste domanda;
- esiste contenuto utile;
- esiste una logica commerciale;
- non finge una sede fisica;
- non contiene casi inventati.

## Search Console

Usare dati reali per decidere:
- nuovi articoli;
- consolidamento di pagine;
- title;
- CTR;
- internal linking;
- eventuali città.

## Lead generation

La SEO deve portare verso:
> Richiedi una valutazione nella tua zona.

La CTA deve essere discreta e coerente con l'articolo.

Il sito deve rispondere prima alla domanda dell'utente.

## Trust

Costruire fiducia con:
- chiarezza;
- prudenza;
- spiegazioni tecniche semplici;
- fonti reali quando disponibili;
- eventuale revisione tecnica reale in futuro;
- assenza di claim commerciali aggressivi.

## Backlink

Non usare backlink automatici.

Asset potenzialmente linkabili:
- guide approfondite;
- schemi;
- utility;
- glossario;
- tool per preparare le osservazioni;
- case study solo se realmente disponibili e verificabili.

## Principio guida

Essere la migliore risorsa italiana utile sul problema, non il sito con il maggior numero di pagine.
